> **По-простому:** `toRef` и `toRefs` сохраняют связь с полем в `reactive`; обычная деструктуризация даёт только копию значения — реактивность теряется.

## Код

```javascript
const state = reactive({ a: 1, b: 2 })
const aRef = toRef(state, 'a')
const { b } = state  // plain value

aRef.value++  // state.a меняется ✅
state.b++     // b не меняется ❌
```

## Как тестировать

- Нажми «aRef.value++» — обновятся и `aRef.value`, и `state.a`.
- Нажми «state.b++» — `state.b` изменится, а `b` (plain) останется старым.

Ожидаемо: с `toRef` переменная и поле в `reactive` синхронизированы; при деструктуризации связь теряется.

## Почему так происходит?

В кейсе «Деструктуризация reactive» мы уже разобрали: при деструктуризации мы читаем значение из объекта и дальше работаем с копией. Vue отслеживает обращение к полю в `reactive`, но не «привязывает» это значение к новой переменной.

`toRef(state, 'a')` делает другое: он не копирует значение, а создаёт **ref**, который при чтении и записи обращается к `state.a`. То есть это не снимок, а живая ссылка на одно конкретное поле. Поэтому `aRef.value++` по сути выполняет `state.a++`, и наоборот.

`toRefs(state)` — то же самое, но для всех полей объекта: возвращает объект, где каждое поле обёрнуто в `ref`, связанный с соответствующим полем `state`.

## Когда использовать toRef, когда toRefs?

- **toRef** — когда нужно «вытащить» одно поле и сохранить реактивность (например, передать в композабл или шаблон по имени).
- **toRefs** — когда нужно раздать все поля объекта (например, после `reactive` в композабле вернуть «плоский» объект ref'ов для шаблона).

> `toRefs` оборачивает **все** поля объекта. Для больших объектов, если нужны только пара полей, выгоднее использовать несколько `toRef`, чтобы не создавать лишние ref'ы.

## Связь с другими кейсами

- **Деструктуризация reactive** — там мы как раз показываем проблему: `const { b } = state` даёт plain value. Решение для «нужна связь» — `toRef` / `toRefs`.
- **Деструктуризация ref** — там речь про `ref`; для примитива внутри `ref` «спасти» реактивность через деструктуризацию нельзя, нужно работать через `.value` или через `toRef`, если значение пришло из `reactive`.

## Что важно помнить

- Деструктуризация `reactive` даёт копию значения, не связь.
- Если нужна связь с полем — используй `toRef(state, 'field')` или `toRefs(state)`.
- `toRef`/`toRefs` возвращают ref'ы: в коде используй `.value`, в шаблоне Vue разворачивает автоматически.

## Термины и ссылки

- **`toRef()`** — создаёт ref, связанный с конкретным полем reactive-объекта. [Документация](https://vuejs.org/api/reactivity-utilities.html#toref)
- **`toRefs()`** — преобразует reactive-объект в объект ref'ов по полям. [Документация](https://vuejs.org/api/reactivity-utilities.html#torefs)
- **`reactive()`** — делает объект реактивным (deep proxy). [Документация](https://vuejs.org/api/reactivity-core.html#reactive)
