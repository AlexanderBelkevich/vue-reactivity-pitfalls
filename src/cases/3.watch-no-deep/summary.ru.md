> **По-простому:** `watch` по объекту без опции `deep` реагирует только на **смену ссылки** на этот объект. Изменения внутри (поля, элементы массива) по умолчанию не отслеживаются.

## Код

```javascript
const state = reactive({
  profile: { name: 'Ира', skills: ['Vue'] },
})

watch(() => state.profile, () => log('shallow'))           // только смена state.profile
watch(() => state.profile, () => log('deep'), { deep: true })  // и смена, и изменения внутри
```

## Как тестировать

- Нажми «Добавить skill» — изменится только массив внутри `profile`, ссылка на `state.profile` та же. Сработает только коллбек с `deep: true`.
- Нажми «Заменить profile» — присваивается новый объект, ссылка меняется. Сработают оба watcher'а.

Ожидаемо: без `deep` реакция только на замену объекта; с `deep` — и на вложенные изменения.

## Почему так происходит?

Vue при слежении за «источником» по умолчанию сравнивает его по ссылке. Источник — это то, что возвращает геттер (или сам ref/reactive). Для `() => state.profile` источником является значение `state.profile` — то есть объект. Пока мы делаем `state.profile.skills.push('Pinia')`, сам объект `state.profile` не меняется: меняется только его внутреннее состояние. Ссылка на объект та же → shallow watch не срабатывает.

Когда мы делаем `state.profile = { name: 'Ира', skills: ['Vue', 'Pinia'] }`, мы подменяем объект. Ссылка меняется → оба watcher'а видят изменение.

Это не «баг» Vue, а осознанное поведение: глубокое слежение дороже (нужно обходить все вложенные поля и отслеживать их), поэтому по умолчанию watch ведёт себя «мелко».

## Когда нужен deep?

- Нужно реагировать на изменение **любого** поля внутри объекта или элемента массива — используй `{ deep: true }`.
- Реагировать нужно только на «подмену» объекта целиком (например, новый ответ с API) — `deep` не нужен, достаточно shallow.

> С `deep: true` Vue отслеживает все вложенные свойства. Для больших или часто меняющихся структур это может быть затратно. Иногда проще и быстрее не мутировать объект, а заменять его целиком (`state.profile = { ...newProfile }`), тогда shallow watch достаточно.

## Альтернативы

- Следить не за целым объектом, а за конкретным полем: `watch(() => state.profile.name, ...)` — сработает при смене имени, без `deep`.
- Если структура сложная, можно следить за несколькими полями или за «нормализованным» значением (например, JSON.stringify для сравнения по содержимому — осторожно с порядком ключей и типами).

## Что важно помнить

- `watch` по объекту без `deep` реагирует на смену ссылки, а не на изменения внутри.
- Вложенные поля и мутации массивов не триггерят такой watch.
- Когда нужна реакция на «всё внутри» — включай `deep: true`; учитывай стоимость для больших объектов.
